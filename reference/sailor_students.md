# assessment data on students from the sailor moon universe

A fictional assessment data set.

## Usage

``` r
sailor_students
```

## Format

\`sailor_students\` A tibble with 12 rows and 6 columns:

- sgic:

  Subject generated ID

- school:

  schoolnumber

- class:

  class designation

- gender:

  gender

- testscore_language, testscore_calculus:

  testscores
