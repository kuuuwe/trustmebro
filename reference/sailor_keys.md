# key data on students from the sailor moon universe

A fictional key data set.

## Usage

``` r
sailor_keys
```

## Format

\`sailor_keys\` A tibble with 12 rows and 6 columns:

- schoolyear:

  schoolyear

- guid:

  hexadecimal ID number

- name, birthday, sex:

  student information

- school, schoolnumber, class, grade_level:

  school information

- sgic1, sgic2, sgic3:

  subject generated ID
